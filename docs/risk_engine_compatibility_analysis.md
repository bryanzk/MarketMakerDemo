## Problem Identified / 发现的问题

### Issue 1: Runtime Spread Adjustment Not Validated / 运行时价差调整未验证

**Problem / 问题**:
- Risk Agent only validates spread when:
  - Config is updated via API
  - Bot/strategy is started
  - LLM proposes a change
- **Dynamic spread adjustment happens at runtime** in `calculate_target_orders()`
- Adjusted spread is **NOT validated** against risk limits
- If adjusted spread exceeds MIN_SPREAD or MAX_SPREAD, it will be used without validation

**Example Scenario / 示例场景**:
```python
# Base spread: 3.5%
# Very high volatility: 3.5% × 1.5 = 5.25%
# MAX_SPREAD: 5.0%
# Result: 5.25% > 5.0% ❌ EXCEEDS LIMIT
```

### Issue 2: Market Spread Consideration / 市场价差考虑

**Problem / 问题**:
- In high volatility, spread can be adjusted to `max(adjusted_spread, market_spread * 1.3)`
- If market spread is very wide (e.g., 4%), then `4% × 1.3 = 5.2%`
- This exceeds MAX_SPREAD (5.0%) ❌

---

## Solution / 解决方案

### Fix: Add Risk Validation to `calculate_adaptive_spread()` / 在 `calculate_adaptive_spread()` 中添加风险验证

**Implementation / 实现**:
1. Import `RISK_LIMITS` in `fixed_spread.py`
2. After calculating `adjusted_spread`, clamp it to risk limits
3. Log warning if clamping occurs
4. Return clamped spread

**Code Changes / 代码变更**:
```python
from src.shared.config import RISK_LIMITS

def calculate_adaptive_spread(...):
    # ... existing calculation ...
    
    # Clamp to risk limits / 限制在风险范围内
    min_spread = RISK_LIMITS["MIN_SPREAD"]
    max_spread = RISK_LIMITS["MAX_SPREAD"]
    
    if adjusted_spread < min_spread:
        logger.warning(
            f"Adjusted spread {adjusted_spread*100:.2f}% below MIN_SPREAD {min_spread*100:.2f}%. "
            f"Clamping to {min_spread*100:.2f}%. "
            f"调整后的价差 {adjusted_spread*100:.2f}% 低于最小价差 {min_spread*100:.2f}%。限制为 {min_spread*100:.2f}%。"
        )
        adjusted_spread = min_spread
    elif adjusted_spread > max_spread:
        logger.warning(
            f"Adjusted spread {adjusted_spread*100:.2f}% above MAX_SPREAD {max_spread*100:.2f}%. "
            f"Clamping to {max_spread*100:.2f}%. "
            f"调整后的价差 {adjusted_spread*100:.2f}% 高于最大价差 {max_spread*100:.2f}%。限制为 {max_spread*100:.2f}%。"
        )
        adjusted_spread = max_spread
    
    self.spread = adjusted_spread
    return adjusted_spread
```
